图9与图10绘图代码（烘干终点：57.2107 h）

⚠️ 编号说明：本包沿用开发时的内部编号（图9/图10），对应论文图10/图11；以论文图题为准。

文件说明：
1. figure9_hovmoller.py：生成图9“水分分布时空演化图”。
2. figure10_drying_rate.py：生成图10“干燥速率—累计脱水率曲线”；坐标轴、刻度、标签和边框均为黑色。
3. run_all.py：依次运行图9与图10代码。
4. requirements.txt：Python依赖列表。

数据文件（须与本包的 .py 放在同一文件夹，已随包提供）：
1) result3.xlsx —— 官方结果表，宽表格式（供图9）：
   首格为「时间\到药材中心的距离」，其后每列一个半径值(cm)、每行一个时刻(s)，60 s 一行。
   表格 3434 行、60 s 一行；末行只是表格最后一行的时间戳 205980 s（= 57.2167 h），
   不是烘干终点。烘干终点按判据 max_r C(r,t) < 0.15 取到 57.2107 h（= 205958.43687243608 s），
   落在倒数第二行(205920 s)与末行(205980 s)之间，所以表格在终点之后再记一行才停。
2) W_history.csv —— 总含水量时程（供图10），列：t_s, W；W 由求解器逐步累加 C·V 得到。
   ※ 图10 不从 result3.xlsx 反算 W：结果表只保留 4 位小数，从它反算在尾段会差约 2.5%，
     故直接读求解器落盘的总水量序列。

运行步骤：
1. 在本文件夹打开终端，安装依赖：
   pip install -r requirements.txt
2. 生成两张图：
   python run_all.py

也可分别运行：
   python figure9_hovmoller.py
   python figure10_drying_rate.py

输出文件：
- fig_q3_hovmoller.png / fig_q3_hovmoller.pdf
- fig_q3_drying_rate.png / fig_q3_drying_rate.pdf

说明：
- 两个脚本均用 Path(__file__) 定位数据与输出，与当前工作目录无关，整个文件夹可任意搬移。
- 图9 直接读宽表：行首列是时间(s)、列头是半径(cm)、单元格是水分浓度 C。
- 换数据只需替换 result3.xlsx / W_history.csv，表结构与上述一致即可。
