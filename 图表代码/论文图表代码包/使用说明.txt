论文图表代码包

包含：
1. 图4_温度场与水分场时空演化.py
2. 图5_表面热通量与传质通量演化.py
3. fig09_q1_flux_balance.json —— 图5 数据来源（溯源材料，运行不需要）

使用方法：
- 整个文件夹拷到任意位置即可，脚本用"自身所在目录"定位数据与输出，与当前工作目录无关。
- 安装依赖：
  pip install numpy pandas matplotlib scipy openpyxl
- 直接运行对应 Python 文件。

数据文件（须与本包的 .py 放在同一文件夹）：
1) result2_full_60s.xlsx —— 官方结果表，宽表格式：
   首格为「时间\到药材中心的距离」，其后每列一个半径值(cm)、每行一个时刻(s)，60 s 一行。
     · 工作表「温度」  ：温度场 T(r,t)
     · 工作表「水分浓度」：水分场 C(r,t)
   图4 取 t = 600 / 1200 / 1800 s 三个时刻的径向分布与圆盘云图。

2) 图5_表面通量数据.csv —— 预热阶段(0~1800 s)表面通量表，列：t_s, q_W_per_m2, j_kg_per_m2_s
   定义与常数口径：
     q = h · (T_air − T_surface)，        h   = 25 W/(m²·K)
     j = ρ_d · h_m · (C_surface − C_air)，h_m = 8×10⁻⁷ m/s，ρ_d = 230.98591549295776 kg/m³
   T_air / C_air 取赛题附件1，T_surface / C_surface 取问题一落盘的表面序列。
   来源：同目录 fig09_q1_flux_balance.json（问题一「表面通量平衡图」的数据入口），
   其 _provenance 记录了生成时的上游锚点 results_sha256 =
   663b5a8eb49baaec32392ccf244362d54193f74ba9430c84fa9923fb373072a3，
   以及附件1 的 attachment1_sha256 与所用公式；已用附件1 与落盘表面序列独立复算，逐点偏差为 0。

输出：
- 图4_温度场与水分场时空演化.png
- 图5_表面热通量与传质通量演化.png

说明：
- 图4 自动读「温度」「水分浓度」两个工作表，无需手工改列名。
- 图5 若只想换数据，替换 图5_表面通量数据.csv 即可，列名保持 t_s / q_W_per_m2 / j_kg_per_m2_s。
- 两份数据文件均按"指标/单位/条件"可反向溯源至提交包 results/ 下的产物。
