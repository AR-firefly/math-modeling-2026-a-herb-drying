# 运行环境说明 —— 2026 高教社杯 A 题《药材的烘干问题》

> 本文件与 `requirements.txt` 一并提交，供评委在本地复现本队结果。

## 一、环境要求

| 项       | 版本                                                                    |
| -------- | ----------------------------------------------------------------------- |
| 操作系统 | Windows 10/11（64 位）；Linux/macOS 亦可，代码不含平台相关调用          |
| Python   | **3.13.7**（3.10 以上应均可运行）                                       |
| 依赖     | 见 `requirements.txt`（numpy / scipy / pandas / matplotlib / openpyxl） |

**依赖强弱**：

- **核心求解（Q1~Q4）只依赖 `numpy`** —— 这是复现数值结果的最小依赖。
- **表格读写**（`result1~4.xlsx`）依赖 `openpyxl`。
- `scipy` / `pandas` 用于部分检验与数据处理脚本。
- **出图**依赖 `matplotlib`（仅当需要重跑作图脚本时才需要）。

## 二、安装

```bash
pip install -r 环境配置/requirements.txt
```

（本节命令均以包根目录为当前目录；若已 `cd` 进 `环境配置/`，去掉路径前缀即可。）

若 pip 安装缓慢，可使用国内镜像：

```bash
pip install -r 环境配置/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 三、目录结构（本包实际）

```
（包根）/
├─ result1.xlsx ~ result4.xlsx   ← 四问最终答案（题面要求的 4 个结果文件）
├─ Q1/  7 个 .py                 ← 问题一代码
├─ Q2/  3 个 .py                 ← 问题二代码
├─ Q3/  4 个 .py                 ← 问题三代码
├─ Q4/  6 个 .py                 ← 问题四代码
├─ 附件/                          ← 题目附件
│   ├─ 附件1.xlsx                烘房温度与含湿量时程
│   ├─ 附件2.xlsx                药材半径随时间变化
│   └─ 附件3/                    题面提交模板
├─ A题.pdf                        ← 题目原文
├─ 数据台账/                      ← Q2/Q3 代码在导入时读取的口径台账
│   ├─ DATA_FACTS.json           题面给定数据（逐位照抄）
│   ├─ DATA_PROFILE.json         附件 1 建档信息
│   ├─ CROSS_PROBLEM_LEDGER.json 跨问口径台账（单位/口径一致性）
│   └─ MODELING_REPORT.md        建模文档（含参数口径表，代码从中解析）
├─ 图表代码/                      ← 论文图表的独立绘图脚本包（3 个子目录，各带使用说明）
└─ 环境配置/                      ← 本文件与 requirements.txt
```

**所有脚本一律按 `__file__` 相对定位包根，不含任何本机绝对路径**，因此可在任意工作目录下运行，也可整包移动到任意路径。

## 四、如何运行

四问的主求解入口（在包根目录执行）：

```bash
python Q1/run_q1.py        # 问题一：预热平衡 0~1800 s   （实测约 100 s）
python Q2/problem2.py      # 问题二：整个烘干过程        （实测约 60 s）
python Q3/problem3.py      # 问题三：烘干时间            （实测约 50 s，依赖问题二已跑完）
python Q4/run_q4.py        # 问题四：收缩域              （实测约 20 s）
```

运行顺序：**问题三依赖问题二**（读取问题二算出的水分场），其余各问相互独立。

四问的产物位置：

- 问题一、问题四 → 写入包根 `results/`
- 问题二 → 写入 `Q2/output/`
- 问题三 → 写入 `Q3/output/`

四个交付文件在三种位置内容一致：包根 `result1~4.xlsx`（最终答案）、各问输出目录、以及 `results/`（Q1/Q4）。

### 问题一的检验脚本

```bash
python Q1/data_prep.py                    # 校验附件 1 数据完整性
python src/verification_q1.py             # 独立验证
python src/convergence_q1.py              # 网格 / 时间步收敛
python src/window_error_q1.py             # 时间窗口误差估计
```

### 问题四的检验脚本

```bash
python src/verify_q4_baseline.py          # 基线对拍（实测约 140 s）
python src/verify_q4_compare.py           # 核心建模选择的替代方案数值对比（实测约 150 s）
python src/verify_q4_convergence.py       # 网格 / 时间步收敛（实测约 160 s）
python src/verify_q4_sensitivity.py       # 灵敏度扫描（E1~E6，耗时较长）
```

> 问题四的 `src/verify_q4_convergence.py` 会生成 `results/q4_convergence.json`；
> 该文件存在时，`Q4/run_q4.py` 会把不确定度条目回填为实测值（否则记为「待回填」）。
> 若要完整回填，请先跑 `src/verify_q4_convergence.py` 再跑 `Q4/run_q4.py`。
>
> Q2/Q3 的验证入口见 `src/README.md`。

## 五、输出说明

- **交付表格**：`result1.xlsx` ~ `result4.xlsx`
  - `result1` / `result2` 各含 **2 个工作表**（`温度`、`水分浓度`），与题面模板 `附件/附件3/` 一致
  - `result3` / `result4` 各含 1 个工作表（`Sheet1`）
- **中间数据**：`.csv` / `.npz` / `.json`，写入包根 `results/`，供检验脚本与作图脚本读取
- **图表**：`图表代码/` 下三个代码子目录各自带 `使用说明.txt` / `README.txt`，按说明运行即可重绘论文主要结果图；`论文原图/` 放从论文 PDF 提取的 Q2/Q4 展示图，不由代码生成

## 六、可复现性说明

- 本队全部结果为**确定性计算，不使用随机数**（`seed = 42` 固定写入运行清单）；未使用方法存在多次运行结果不同的问题。
- 求解依赖的版本号已在 `requirements.txt` 中**钉死**；`环境说明.md` 记录 Python 版本。
- 所有结果性数字在论文中均可按「指标 / 单位 / 条件」反向溯源到脚本输出。
- 各脚本运行后会写运行清单（`results/run_manifest*.json`），内含**输入附件与脚本的 sha256**，可用于核对「跑出来的是不是同一套」。

## 七、常见问题

**Q：报错 `FileNotFoundError: …附件1.xlsx`？**
A：确认 `附件/附件1.xlsx`、`附件/附件2.xlsx` 与 `A题.pdf` 在本包内的原始位置未被移动（见第三节）。代码按相对路径读取，整包移动不影响。

**Q：报错 `FileNotFoundError: …数据台账/DATA_FACTS.json`？**
A：`数据台账/` 是问题二、三代码**在导入时即读取**的口径台账，请勿移出或改名。

**Q：`ModuleNotFoundError: No module named 'openpyxl'`？**
A：未安装依赖，在包根目录执行 `pip install -r 环境配置/requirements.txt`。

**Q：中文字体显示为方框？**
A：仅影响出图，不影响数值结果。matplotlib 会尝试使用系统中文字体（微软雅黑 / 黑体）；Linux 下可安装 `fonts-noto-cjk`。

**Q：结果文件里的数字能对上论文吗？**
A：`result1.xlsx` ~ `result4.xlsx` 即为论文取数的来源，包内已附一份（运行后会被重算覆盖，数值一致）。
